# OpenContext Site

Marketing and documentation site for **OpenContext** — the open source MCP framework that connects government open data portals to AI assistants.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- shadcn/ui (Radix)

## Routes

| Path | Page |
|------|------|
| `/` | Home |
| `/docs` | Documentation |
| `/connect` | MCP connection guide |

Permanent redirects: `/home` → `/`, `/how-it-works` → `/docs`, `/bulletin` → `/`.

## Develop

```bash
npm install
npm run dev
```

```bash
npm run build
npm run lint
```
